# نظام New Graphic ERP

<div dir="rtl">

## نظرة عامة

نظام تخطيط موارد المؤسسات (ERP) متكامل مخصص لشركات الدعاية والإعلان، المطابع، وورش اللافتات الخارجية (الأوت دور).

## الميزات الرئيسية

### 📊 الوحدات الأساسية

1. **إدارة علاقات العملاء والمبيعات (CRM & Sales)**
   - إدارة بيانات العملاء الكاملة
   - إنشاء عروض أسعار احترافية
   - تحويل عروض الأسعار إلى أوامر شغل
   - تتبع سجل التعاملات

2. **إدارة الإنتاج والمشاريع**
   - لوحة تتبع مرئية (Kanban Board)
   - إدارة أوامر الشغل
   - تتبع المراحل الإنتاجية
   - إدارة ملفات التصميم

3. **المحاسبة المالية المتكاملة**
   - دليل حسابات مرن
   - قيود يومية تلقائية
   - فواتير المبيعات والمشتريات
   - إدارة الموردين والمصروفات
   - تقارير مالية شاملة

4. **إدارة المخزون والمستودعات**
   - تتبع المواد الخام
   - إدارة إذن الإضافة والصرف
   - تنبيهات المخزون المنخفض
   - الجرد الدوري

5. **إدارة المستخدمين والصلاحيات**
   - نظام أدوار وصلاحيات متقدم
   - تحكم دقيق في الوصول
   - سجل الأنشطة (Audit Log)

6. **لوحة التحكم والتقارير**
   - لوحة تحكم تفاعلية
   - مؤشرات الأداء الرئيسية
   - مولد تقارير مخصصة
   - رسوم بيانية تفاعلية

## التقنيات المستخدمة

### Backend (الخادم)
- **PHP 8.x** - لغة البرمجة
- **Laravel 10.x** - إطار العمل
- **MySQL 8.x** - قاعدة البيانات

### Frontend (واجهة المستخدم)
- **Vue.js 3** - إطار العمل
- **Bootstrap 5 RTL** - التصميم
- **دعم كامل للغة العربية**
- **تصميم RTL مثالي**

### الأمان
- تشفير كلمات المرور
- حماية من XSS, CSRF, SQL Injection
- نظام صلاحيات صارم (RBAC)
- سجل الأنشطة الكامل

## التثبيت والإعداد

### 1. استنساخ المشروع

```bash
git clone https://github.com/esraa222102044/esraa222102044.github.io.git
cd esraa222102044.github.io
```

### 2. إعداد Backend

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan db:seed
```

### 3. إعداد Frontend

```bash
cd frontend
npm install
npm run dev
```

### 4. تشغيل النظام

**Backend:**
```bash
cd backend
php artisan serve
```

**Frontend:**
```bash
cd frontend
npm run dev
```
